HYA / EXPERIMENT 001

声音，也有形状。

让一段声音留下纹理。观察它，播放它，发现它的变化。

本机运行 · 无需账号 · 离线分析
从示例开始，或导入 WAV / MP3 / M4A / AIFF。最长 120 秒，最大 32 MB。
01 / SONIC FINGERPRINT
圆周表示时间，轮廓表示能量，三层纹理分别对应低、中、高频。
02 / ACOUSTIC FEATURES
—时长 / 秒
—当前频谱重心 / Hz
—当前 RMS / dBFS
03 / LISTEN & OBSERVE
播放、暂停或拖动进度，观察同一枚指纹的动态变化。

这是声学特征的视觉表达，不是情绪识别。相同输入在同一算法版本下产生相同参数；不承诺转码后相同或跨设备像素级一致。
