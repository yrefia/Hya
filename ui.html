HYA / EXPERIMENT 001

让旋律，成为线条。

旋律走向、伴随音高与背景纹理，在时间里交织。

本机运行 · 无需账号 · 离线分析
从示例开始，或导入 WAV / MP3 / M4A / AIFF。最长 10 分钟，最大 128 MB。
01 / MELODY / HARMONY
金色：旋律候选 · 绿 / 蓝 / 紫：伴随音高 · 暗线：背景纹理。音高越高，线的位置越高；无可靠音高时断开。
02 / ACOUSTIC FEATURES
—时长 / 秒
—当前频谱重心 / Hz
—当前 RMS / dBFS
03 / LISTEN & OBSERVE
播放、暂停或拖动进度，观察同一枚指纹的动态变化。

这是混合音频的音高轨迹估计，不是人声 / 乐器分离。主旋律可能被较响的伴奏取代，复杂和弦也可能漏检。相同输入在同一算法版本下产生相同参数；不承诺转码后相同或跨设备像素级一致。
